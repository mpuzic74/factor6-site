# Factor6 website (factor6.ca)

## What this is
One-page public website for Factor6 Inc. Plain HTML, hosted on GitHub Pages at https://factor6.ca (CNAME file). This repo is PUBLIC: never commit anything private.

## How to change it
Edit index.html, commit, push to main. The site updates in about a minute.

## Brand
Follow the Factor6 brand guide (iCloud: 5 - Work/04 - Brand & Visibility/05 - Brand Kit/factor6-brand-guide.md): Jost font, hex mark.

## Writing
Plain, direct copy. No em dashes, no rule-of-three phrasing, no AI-sounding filler.
